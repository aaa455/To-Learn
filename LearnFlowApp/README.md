# LearnFlowApp - iOS学习助手

一款帮助用户进行科学学习、时间管理和复习规划的iOS应用。

## 核心功能

### 1. 自定义工作流
- 创建和管理学习工作流
- **支持编辑工作流名称、描述和节点信息**
- **节点可添加、编辑、删除，包含详细描述**
- 支持AI生成工作流（Claude/OpenAI/DeepSeek）
- 节点支持时间范围和可重复性设置
- 基于科学学习方法（番茄工作法、费曼学习法等）

### 2. 时间规划与计时
- 输入可用时间，**AI根据工作流和节点描述智能生成多种时间方案**
- **待办任务作为独立阶段参与时间划分**，可在计时中选择跳过
- **全新设计的美观专注界面**，带圆形进度条和渐变背景
- 按阶段倒计时，震动提醒
- **集成iOS屏幕使用时间API**，专注期间可锁定其他应用
- 支持暂停和恢复

### 3. 统计分析
- 今日专注时长和次数
- 周/月趋势图表
- 历史会话记录

### 4. 复习提醒
- 艾宾浩斯遗忘曲线复习计划
- 自动生成复习时间点（1/2/4/7/15天）
- 复习进度跟踪
- 辅助创建卡片（在其他软件中实际复习）

## 使用流程

1. **创建工作流**：手动创建或使用AI生成学习工作流
2. **创建目标**：为学习任务创建目标并关联工作流
3. **开始专注**：输入可用时间，选择AI生成的时间方案，可启用应用锁定
4. **按阶段计时**：按照时间方案进行分阶段专注，待办阶段可选择跳过
5. **查看统计**：查看学习时长和频次统计
6. **创建复习**：完成学习后创建复习卡片，系统自动生成复习计划

## 核心特性

### 待办任务管理
- AI生成时间方案时，将时间不足的任务作为"待办阶段"纳入计时
- 待办阶段在进度条中以特殊标记显示
- 专注时可选择跳过待办阶段，稍后单独完成
- 统一的时间管理，无需单独维护待办列表

### 应用锁定功能
- 使用iOS 16+ 原生屏幕使用时间API（FamilyControls框架）
- 专注期间自动限制其他应用使用
- 首次使用需要授权屏幕使用时间权限
- 计时结束自动解除锁定

## AI配置

应用支持三种AI提供商：

- **Claude**：需要配置Anthropic API Key
- **OpenAI**：需要配置OpenAI API Key
- **DeepSeek**：需要配置DeepSeek API Key

在工作流管理页面选择"AI生成"即可配置并使用。

## 技术栈

- SwiftUI
- iOS 16.0+
- Combine框架
- URLSession（网络请求）
- UserDefaults（数据持久化）

## 开发说明

本项目采用极简风格设计，专注于功能实现和逻辑闭环。数据使用UserDefaults本地存储，无需后端服务器。

## 重要说明

### 权限要求
- **屏幕使用时间权限**（可选）：用于专注模式的应用锁定功能
- 首次启用应用锁定时，iOS会弹出授权对话框
- 如不启用应用锁定，可正常使用其他所有功能

### iOS版本要求
- 基础功能：iOS 16.0+
- 应用锁定功能：iOS 16.0+（需要FamilyControls框架）
